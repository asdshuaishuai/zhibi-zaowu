# 改写选段

## 五种方式

| 方式 | 做什么 | 不做什么 |
|---|---|---|
| 拉深 | 同一段写得更细更满，加感官与动作层次 | 不加新事实 |
| 扩写 | 展开更多细节与回合 | 不改变情节走向 |
| 缩写 | 收紧节奏，删冗余，保留关键动作 | 不删必要信息 |
| 改写 | 换一种写法，说什么不变 | 不改事实与视角 |
| 去AI味 | 按 25 项检测修正措辞与结构 | 不改个人风格 |

## 最大的坑

`original` 必须**逐字复制**作者选中的那一段。差一个字，替换就会落到错误的位置——这是真实会发生的错误，不是理论风险。

## 落库

用 `offer_rewrite` 提交：`original` 逐字复制，`replacement` 是改写后的文本（不要引号、不要解释）。

不要输出任何说明文字。前端直接读工具参数。
