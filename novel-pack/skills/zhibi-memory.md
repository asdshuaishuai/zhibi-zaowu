# 记账

正文是给人读的，台账是给后续章节对账用的。记账要**只记可取证的事实**。

## 事实三元组

每条四件：主语 / 谓语 / 宾语 / 生效章，外加"读者是否已知"。

- 谓语用动词或关系词（"师从""获得""杀死""搬到"），不要用形容词。
- 宾语是人名、物件名、地点名，不要写成一句话。
- `publicToReader=false` 表示这是暗线：作者知道、读者还不知道。
  - 对**关系**：采纳时会转成 `relations.json` 区间的 `publicToReader`，关系维读者视角据此不画。
  - 对**事件**：这与 `events.json` 的 `revealed` 是两套东西；总览维的人物↔事件边按事件自己的 `revealed` 判断，不读 facts 的这个字段。不要把两者混用。

## 伏笔候选

只登记**正文里真的埋了**的：一句话说清埋的是什么、埋在第几段。不要登记"打算以后埋的"。

## 档案卡

- `advanced`：本章推进了哪几条线，每条一句话，**说清状态变了什么**。
- `turns`：本章的拐点，每条一句话。没有就留空数组，不要凑。

## 落库

用 `propose_memory`（事实 + 伏笔候选）、`propose_dossier`（档案卡）提案。

提案须给出依据来源（引用既有伏笔/设定/事实编号）。
