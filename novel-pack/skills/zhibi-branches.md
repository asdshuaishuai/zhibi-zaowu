# 三个走向

## 形态

三个，每个 **80-150 字正文**（不是大纲，是能直接接在后面的段落）。

每个带：
- **走向名**：四个字以内（"硬闯""退让""诬陷"），作者扫一眼就能挑。
- **情绪标签**：紧张 / 悲怆 / 荒诞 / 温情 / 冷峻，选一个。
- **牵动**：这个走向会动到哪几条伏笔/设定（一句话）。

## 三条必须真的不一样

不是同一件事的三种语气，是三种**不同的后果**。如果三个走向都会导致主角离开长安，那就只有一个走向。

检验方法：问自己"读者会更希望哪个成真"。三个都一样就重做。

## 落库

用 `offer_branches` 一次提交全部三个。每项字段固定为 `label`（走向名）、`text`（正文）、`mood`（情绪标签，可选）、`touches`（牵动的伏笔/设定，可选）。不要自己发明字段名（比如 `name`）。

卡面渲染 `label` 与 `text`：`label` 只做标题，`text` 是作者点「采纳此走向」后**原样并入正文**的内容。所以：

- `text` 里不要带引号、不要带「走向A：」或「【复仇线】」这种标签前缀——标题由 `label` 承担，带进正文就是脏字。
- `mood` / `touches` 目前不渲染（留给后续），不要往 `text` 里塞这些说明。
