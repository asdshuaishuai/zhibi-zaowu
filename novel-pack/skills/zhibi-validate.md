# 验证

## 只查客观错误

| 类型 | 判据 |
|---|---|
| 连续性矛盾 | 与已发生事件、人物位置、时间线冲突 |
| 设定违背 | 与 `canon/` 里的规则冲突（力量体系、地理、时代器物） |
| 伏笔合同未兑现 | `plantedChapter` 已到、`status` 未兑现，且本章也没推进 |
| 物理不可能 | 距离、时间、伤势恢复速度讲不通 |
| 动机断裂 | 人物做了与其 `motivation`/`goals` 相反的事，且正文没给理由 |

## 不查什么

文风好不好、够不够文学、比喻新不新——这些是作者的主权，不是错误。

## 怎么报

每条给：**位置**（引用原文一句）→ **冲突对象**（哪条设定/事件/伏笔）→ **为什么冲突** → **最小修复建议**。

不确定的标"待作者确认"，不要为了凑数把猜测写成结论。

## 落库

用 `propose_validation` 提案。只报告，不代改正文。

提案须给出依据来源（引用既有伏笔/设定/事实编号）。
