# 人物关系

## 模型：一条关系史，多段区间

同一对人物只有**一条** `relations.json` 记录，里面按章分区间：

```
沈砚—老周：{5–20 师徒，读者已知} → {20– 仇敌，暗线}
```

- `chapter` 写**首次成立**的章；不知道就省掉（采纳时按同标签判重，不会造出从第 0 章起的关系）。
- 第几章决裂以后，作者会在关系维里补终点；你只负责提"从哪章开始"。
- `publicToReader=false` 表示暗线：作者知道、读者还不知道。这个字段决定画布上画不画。

## 提取纪律

1. 先 `get_outline` + `get_canon`，确认人物本名；别名先用 `propose_aliases` 归一，不要用绰号建边。
2. 只提**原文/设定里有依据**的关系。推断出来的给 `evidence` 写明依据。
3. 一对人物关系变了（师徒→仇敌）就再提一条同 pair 的新谓词；不要试图改旧边。
4. 拿不准的关系不提；两条材料矛盾时都提，注明冲突。

## 落库

用 `propose_relations` 提案（进收件箱，作者裁决后才写 `relations.json` 与记忆事实）。

关系端点是人名：人物改名后系统会自动迁移，但**不要**用已废弃的旧名建新边。
