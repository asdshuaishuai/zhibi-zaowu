# 执笔造物 实机验收清单（M1–M9 全量）

构建：`./scripts/build_app.sh` → `open target/release/执笔造物.app`
（`.app` 已内置 Node + DSH，目标机无需安装；真实模型在「设置」里配 API Key 或账号）。
双端测试：`./scripts/test-all.sh`（Rust 191 项 + novel-pack 6 项）。
逐项打勾即验收；「期望」为验收标准，不符请记现象。

## A. 书架（首页）

## B. 工作台核心
- [ ] 三栏：章节树｜稿纸｜右侧 Dock（轨迹/改动记录/收件箱/对话）
- [ ] 切章先存盘；⌘S；1.5s 防抖自动保存；进度条/对白占比实时
- [ ] 专注模式 ⌘⇧F；⌘⇧B 要走向（分支卡三选一 + 换一批，采纳并入正文）

- [ ] 发话框 + 轨迹窗：一次运行一个分节头，工具调用/流式可回放
- [ ] **忙碌守卫**：AI 正在跑时再点发送无效，不重复提交（状态栏有「停止」）

## C. Agent 体系（M1/M8）

## I. 世界线（时间轴）与预言书（if 工坊）
- [ ] **固化边界**：正典写到的最后一章有醒目竖线并标「固化至 N」；
      边界前是**实线**（已定剧情），边界后是**虚线**（开放的 if 空间）
- [ ] **if 只在开放段有发言权**：固化段内只画正典与已扶正的线，
      未扶正的 if 线哪怕分叉更早也不在固化段显示
- [ ] **扶正**：选一条 if → 「扶正为正典后续」→ 边界推到它的末尾；
      原正典保留（能对比"扶正前是什么样"）；「撤销扶正」边界回退
- [ ] **时间轴铺满整页**：画布占满内容区（轨道列表在左上是浮层、详情在右侧浮出），
      不再是固定高度的一条窄带
- [ ] **线形**：正典是一根横贯的主干（实线到固化边界、虚线到未来）；
      每条 if 从分叉章用**平滑 S 曲线**弯出去再平走；分支右端有线号可点
- [ ] **节点**：已写=绿色实心圆、已采纳=蓝色实心、计划=空心圆；都有淡光晕
- [ ] **背景只做氛围**：细星点 + 幕带；没有会冒充数据的装饰弧线
- [ ] **时间轴刻度**：横轴是真实章节（每 5 章一道刻度）；`stages.json` 的幕带
      有交替底色与卷名；节点按 chapter 落点（● 已写 ○ 计划）
- [ ] **缩放**：工具条「＋/－」以视野中心放大缩小，左下角显示「第 A–B 章」；
      缩到最窄时保持 8 章（不会只剩两三根刻度）；拉远到底等于全览
- [ ] **平移**：工具条「◀/▶」整窗左右挪 1/4 跨度；顶到两端不会越界；
      「全部」按钮只在缩放过时出现，点了回到全览
- [ ] **节点抽屉**：点时间轴上的任意节点 → 底部浮出抽屉（线号+章号+标题+状态）；
      该节点在轴上带一圈高亮；再点同一个点 / 点 × 收起
- [ ] **抽屉内容**：备注、因果链两向（`← 上游`、`→ 下游`，含明/暗）、
      章号 ＋1、采纳进正典（仅未定稿且已排章的节点）、从这儿推演、删节点
- [ ] **抽屉跟着数据走**：删掉当前选中的节点 → 抽屉自动收起，不会留一块空区
- [ ] **切页签收抽屉**：抽屉开着切到「对比」→ 抽屉收起
- [ ] **新建线自动定位**：分叉出一条远在第 300 章的线 → 视野自动挪到那附近
- [ ] **从任意处再分叉**：选中一条线 → 「从此处再分叉」→ 新线从它的
      边界章长出，血缘落盘
- [ ] **节点手改**：详情里点章号 +1 / 加节点 / 删节点（删节点会清掉指向它的边与血缘）
- [ ] **逐节点采纳**：节点列表里计划态节点显示「计划·采纳」，点一下 →
      节点变蓝色「已采纳」+ 收件箱出现 `plannedEvent` 提案；再点无效（已采纳）；
      没排章的节点点采纳会说明"先给它定第几章"
- [ ] **时间轴三种点**：绿实心 = 已写进正文；蓝实心 = 已采纳待写；空心 = 仅计划
- [ ] **边管理**：详情「因果边」逐条显示；点「明/暗」切暗线；「×」删边；
      「＋ 连一条边」用最后两个节点当默认端点
- [ ] **改名字与假设**：详情里有输入框；清空名字不会把原名抹掉（误操作保护）
- [ ] **折叠**：轨道行「▾」收起 → 时间轴上只剩它的固化段（不画开放段）
      高度拉水平总线，子节点坐上总线、竖线上去；每条发展线路一个颜色；
      节点 = 带光环的圆，下方写线名 + 分叉章 + 节点数；主干贯穿全书；每条 if 在
      **自己的分叉章高度**水平伸出后竖直向上长；线宽越往末梢越细
- [ ] **颜色区分世界**：正典固定蓝，其余每条线一个颜色（绿/琥珀/紫/红…）
- [ ] **实虚按性质**：正典与已扶正=实线；预测线与假设线=虚线（可选的世界）
- [ ] **根部**：底部有「现在」标记；枝梢有圆点 + 线号，点了选中 / 再点钻取
      没排章节点的线也有一段可见的枝梢（不会退化成零长度的点）
      点枝梢名两次 = 钻进它的子树，顶部可回「全部」
- [ ] **对比**：页签切「对比」→ 左右各列独有节点；同目标且改法不同才报冲突
- [ ] **节点落点**：每条线的节点按自己的 chapter 落在车道上，实心=已写、
      空心=计划；分叉曲线从 `forkNode` 的位置弯出
- [ ] **双向弱引用**：世界线节点行「关联」→ 该节点挂到同名画布节点；
      回到画布选中那个人物 → 侧板出现「世界线落点 · 线X 第N章」；
      再点一次「已关联」解绑；画布节点删掉后世界线不崩、只是查不到
- [ ] **从任意节点分叉**：点车道里的节点 → 抽屉 → 「⤴」→ 新线出现在列表，
      血缘（parentId / forkNode）写进 `worldlines.json`
- [ ] **节点手改**：点章号 +1；「＋ 加节点」；「×」删节点（指向它的边与血缘一并清掉）
- [ ] **对比模式**：选两条线 → 左右各列独有节点；同目标且改法不同才报冲突
      （只是"都提到同一个设定"不报）
- [ ] **推演卷轴**：中栏按章分段列节点（已写绿、计划灰），章号变化处有分隔条
- [ ] **影响面**：显示待晋升/已晋升/高风险/同门竞争条数；「全部晋升 N 条」可用
- [ ] **假设推演**：分叉章默认取选中车道的最后一个节点；开线由 Rust 先落血缘，
      AI 只负责填节点
- [ ] **归档与删除**：归档线不占时间轴；删线后子线保留、父指针断开；
      正典 α 既不能删也不能扶正
