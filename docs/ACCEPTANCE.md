# 执笔 3.0 实机验收清单（M1–M7 全量）

构建：`./scripts/build_app.sh` → `open target/release/执笔.app`（依赖：Node≥24.9 + `npm i -g @deepseek-ai/dsh`；真实模型需 `DEEPSEEK_API_KEY`）。
逐项打勾即验收；「期望」为验收标准，不符请记现象。

## A. 书架（首页）
- [ ] 旧 SwiftUI 项目（如《断刀记验证》《赤星》）直接列出，字数/状态正确
- [ ] 新建作品向导；封面题签/目标环/相对时间观感（重点：是否还「太丑」）
- [ ] 导入旧稿 → 章节启发式识别 → 提案进收件箱（不直接落库）

## B. 工作台核心
- [ ] 三栏：章节树｜稿纸｜右侧 Dock（轨迹/收件箱/对话三页签）
- [ ] 切章先存盘；⌘S；1.5s 防抖自动保存；进度条/对白占比实时
- [ ] 专注模式 ⌘⇧F；⌘⇧B 要走向（分支卡三选一 + 换一批，采纳并入正文）
- [ ] **选区浮条**：正文划选一段 → 「选区创作 ▸ 已选 N 字」浮条自动浮现；点空处取消选择 → 浮条消失（≤220ms）；五键（拉深/扩写/缩写/改写/去AI味）→ SelectionDraft 气泡双落点
- [ ] 发话框 + 轨迹窗：一次运行一个分节头，工具调用/流式可回放

## C. 提案闭环（铁律）
- [ ] 搭骨架/一键验证/去AI味/记一笔/盘点/归类 各跑一遍：产出全部进收件箱，**正文与台账零直写**
- [ ] 采纳=幂等（重复点无效）；草稿采纳前自动快照；拒收可回灌理由
- [ ] 十二类提案采纳全真实落库：canon/clues/canonClassify/draft/canonRevise/outlineUpdates/
      skeleton/report/deslop/memoryPack/dossier/clueFixes（deslop 逐处替换+快照先行；memoryPack 去重；
      clueFixes 只动台账与动作日志）；无工具历史名 kind 如实报错不静默

## D. 结构三件套（M7 新验收面）
- [ ] **剧情画板**：节点卡=线/事件/人物/伏笔/设定五类；灰实线=挂线、琥珀=伏笔埋收、绿=人物牵涉、紫虚线=暗线；拖节点/空白平移/±/⊡ 缩放；点选→右侧一阶影响半径；**空白 Shift 拖拽橡皮筋框选成组→组内一起拖**；「读者视角」切换隐去未揭示与暗线；重开面板位置保留（canvas.json）
- [ ] **世界线（原导演台）**：8 章窗口排期板；拖事件/伏笔卡跨列→台账 chapter/plantedChapter 真变（作者主权通道，重开仍在）；幕带显示卷名（《断刀记验证》第一卷/第二卷）；底部预警条（空章红/静默伏笔琥珀/断线红）；列级「AI 核对」→轨迹窗见 director_task 全流程
- [ ] **预言书（双态）**：左列分三组——**已固化·织实**（α 卡显成稿 N 章/定事 N/伏笔兑现 N/N，只读）、**预测线·往哪织**、**假设线·如果改**；假设→「假设推演」→轨迹窗见 get_world_state/propose_worldline/simulate_worldline→影响清单；**晋升**→收件箱→采纳修订设定时 `canon/backups/` 有原文备份；重复晋升被拒；衍生带 `line:β` 标
- [ ] **预测续写**：composer 点「预测续写」→ 轨迹窗见 forecast_task（fork 自动=最新成稿+1，产 2-3 走向）；世界线列表出现绿色 kind 标记的预测线
- [ ] **预测排期（世界线）**：有 forecast 线未晋升计划时，世界线排期板尾部出现「预测候选」虚线列；拖入某章列 → 收件箱得「计划事件→第N章」提案 → **采纳后** events.json 出现 E{seq} happened=false——不采纳绝不入账（对比：实卡拖列是直写）
- [ ] **画布维度**：底栏七页签 总览/设定/人物/关系/时间/事件/转折——关系维应呈中心辐射+谓词边（师徒/获得…）；时间维事件按章折行成链；转折维出 dossier 拐点红边（无档案卡数据则为空提示）；各维拖卡位置互不串（canvas.json dim:id 键）
- [ ] 全程铁律复核：任何 AI 产出都不改正文/台账/设定，只有「采纳」才落库

## D2. 书目与别名（本轮机补）
- [ ] 侧栏「书目信息」：题材/简介/目标章数/章字数目标可改并保存；保存后编辑器进度环分母立即生效、书架题材立即显示
- [ ] 别名提案（propose_aliases）采纳后：人物页/画布人物维与关系维立即有数据（此前新项目恒空）
- [ ] 收件箱三块结构：依据（缺失显式警示）/内容预览（逐条可展开）/落点·回滚；等拍板 N / 已决 M 计数；已决历史含拒收理由
- [ ] 未配置 hostApply 令牌时，AI 调用 apply_proposal 必被拒（工具面铁律）
