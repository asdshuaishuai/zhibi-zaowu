# 世界线与剧情预演（作者指南）

世界线不是排期板，也不是画布。它回答：**剧情已经确定到哪一章、之后有哪些 if、某条 if 怎么变成正典。**

- 侧栏「世界 → 世界线」：时间轴，看主干、分支、固化边界。
- 侧栏「世界 → 预言书」：if 工坊，写假设、让 AI 推演、看影响清单。
- 侧栏「世界 → 章节排期」：章 × 幕的工作排期，**与世界线无关**。

## 1. 四个概念

| 概念 | 含义 |
|---|---|
| **正典 α** | 已经写进正文的那条线，是事实基准。不可归档、不可被推演覆盖。 |
| **沙盒 β/γ…** | if 线。`what-if` = 如果改成这样；`forecast` = 按大纲/成稿往前推「接下来会怎样」。沙盒改动不进正文。 |
| **固化边界** | 剧情确定到第几章：取「非空正文最大章」与「正典/已扶正线自己的边界」的最大值。边界之后才是开放 if。 |
| **扶正 fixed** | 作者把某条 if 线收进正典后续。正典保留原版用于对比，目标线 `kind=fixed` 落盘。 |

## 2. 开一条线

两种入口，区别在**谁先落血缘**：

### 2.1 假设推演（what-if）

1. 世界线页选中一条线（或某个节点），点「从此处再分叉」；预言书页也可以直接「假设推演」。
2. **宿主先建线**：`fork_at_chapter` 写入 `parentId`、`forkNode`、`forkedChapter`。
3. AI 收到任务后只负责 `simulate_worldline` 填节点/边/影响，**不要再调 `propose_worldline` 开第二条线**。
4. 如果宿主没能建线（例如世界线文件为空），AI 才会自己开一条无血缘的线；这是例外，不是默认路径。

### 2.2 预测续写（forecast）

预言书页点「预测续写」。宿主不预建线，AI 用 `propose_worldline(kind=forecast)` 开线，fork 章默认取最新成稿下一章，然后 `simulate_worldline` 写入推演结果。

## 3. 看推演结果

推演结果落在沙盒线里，不碰正典：

- **节点**：第几章发生什么，`state` 为 `planned|adopted|written|branch-only`。
- **边**：因果/埋设/回收/卷入/冲突/暗线。
- **影响清单 diffs**：这条假设对正典的影响，每条写「目标 / 原状 / 新状态 / 为什么」。

生产正典内容前，先看影响清单；影响清单本身不是正典。

## 4. 把预演变成正典（三条路）

### 4.1 逐条晋升影响（promote_diff）

预言书右列影响清单，每条点「晋升」：

- 设定新增 → `propose_canon`
- 设定修订 → `propose_canonRevise`（采纳前自动备份原文）
- 伏笔 → `propose_clues`
- 人物 → `propose_aliases`
- 事件/故事线 → `propose_outlineUpdates`

生成的是**提案**，还要去收件箱采纳。采纳时才写 `promoted`；拒收后可以再次晋升。

### 4.2 按章晋升（promote_diff_chapter）

事件类影响可以指定章号，生成 `plannedEvent` 提案（`happened=false`），采纳后进 `events.json`，在排期板/画布上显示为计划事件。

### 4.3 逐节点采纳（adopt_node）

时间轴上点一个计划节点 →「采纳」：

1. 生成 `plannedEvent` 提案，节点状态**此时仍是** `planned`。
2. 去收件箱**再采纳一次**，才写 `events.json`，节点转 `adopted`。
3. 正文写到该章时，所有 `adopted` 且章号 ≤ 最新成稿章的节点自动转 `written`。

> 关键：逐节点采纳是**两步**。只点时间轴上的「采纳」不会进正典；收件箱那一票才算。

### 4.4 扶正整条线（fix_line）

世界线页对一条 if 线点「扶正」：`kind → fixed`，正典 `fixedThrough` 推到该线边界。扶正不改正文；正文仍由作者写。撤销扶正会退回 `what-if` 并重算正典边界。

## 5. 边界与安全

- **α 不可被 `simulate_worldline` 覆盖，也不可归档**；推演只能对沙盒线做。
- 重推演按节点 id 保留旧的 `chapter/state/note`，不会因为 AI 少写字段就清空状态。
- 归档线不参与全局固化边界，也不在时间轴上显示。
- `branch-only` 表示只在这条分支存在的节点；正文不会把它当正典。

## 6. 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| 开了假设线却多出一条无血缘线 | AI 照旧版技能又调了 `propose_worldline` | 删掉多余的线；当前技能已改为“宿主已开线，直接 simulate” |
| 逐节点采纳后正典没变 | 只完成了第一步 | 去收件箱再采纳 `plannedEvent` 提案 |
| 时间轴边界比正文靠后 | 正典/扶正线上有计划节点 | 计划节点不写正文就不会转 `written`；检查是否需要清掉或改章 |
| 预测线没有父线 | forecast 由 AI 自己开线，宿主不预建 | 在预言书页确认线 id，再推演 |
