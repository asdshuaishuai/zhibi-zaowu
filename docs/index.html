未来八章排在一块板上。卡拖进哪一章、哪条线断了、哪条伏笔放得太久，规则一条条算给你看—— 不是印象，是账。

02

你写，它记账

WHO DOES WHAT

你

  1. 正文只有你能写，AI 手里没有写正文的接口
  2. 提案来了，一条条看：要，或者不要——不要就说原因
  3. 采纳前自动存一份，后悔了能退回去
  4. 拖卡改期、拖节点挪位，都是你亲手改的

它

  1. 产出都先写进提案箱：设定、伏笔、骨架、草稿、关系、大纲
  2. 每条都写清楚：这是从哪条设定、哪条伏笔推出来的
  3. 调了什么工具、传了什么参数、出了几条，轨迹里都看得见
  4. 它拿不到「采纳」那把钥匙，只能提，不能定
03

「如果当初」可以有很多个

WORLDLINE

世界树

主干从第 1 章长到现在，像一棵树的干。你在某一章问一句「如果当初……」，就从那里分出一枝： 枝上结的果，是那个世界已经推演过的事；叶子是还没写的可能。

  • α · 主线，已经写成只读
  • β · 如果那一箭没挡下第 11 章
  • γ · 照着大纲往下推第 24 章
  • δ · 如果旧账没翻到第 18 章

同一份世界线能看两遍：并轨图是平行线，世界树是一棵树。归档的世界留成枯枝。 演示稿《断刀记》，三十章，四条线。

GET / SOURCE

现在只发源码。

克隆下来跑两个脚本，得到自带运行时的 .app。换一台 Mac 打开就能写， 不用装 Node，也不用 npm。

稿子 在 ~/Documents/执笔/*.zhibi，旧版执笔的书直接能开
密钥 只放在本机，不上云；模型可指向局域网里的端点
系统 目前是 macOS，Linux / Windows 要在那台机器上自己编
怎么编 ↗ 仓库 ↗ 
$ git clone https://github.com/asdshuaishuai/zhibi-zaowu
$ cd zhibi-zaowu
$ scripts/vendor_runtime.sh   # 一次性内置 Node + DSH（约 875 MB）
$ scripts/build_app.sh        # → target/release/执笔造物.app
$ open "target/release/执笔造物.app"
