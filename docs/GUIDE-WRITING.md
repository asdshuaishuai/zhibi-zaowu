# 第一次写一章（作者指南）

这份指南只回答一件事：**从零到一章正文落盘，点哪里、先后顺序是什么、哪一步会被拦。**

> 术语：稿纸 = 编辑器页；收件箱 = 右侧 Dock 第二页；章节页 = 侧栏「写作 → 章节」。

## 0. 新建一章

1. 侧栏点「章节」进入全书目录。
2. 右上「新建章」——默认建在最后一章之后，并直接进入稿纸。
3. 也可以点侧栏底部「新建章」。

新建只创建章目录与空稿纸；空正文不算成稿，不计入进度。

## 1. 搭骨架（写前契约）

稿纸上方工具条点「搭骨架」。AI 会按上一章结尾、伏笔到期、故事线位置出 4–6 个节拍，**以提案形式进收件箱**，不会直接写正文。

骨架提案在收件箱里长这样：

```
第 12 章 节拍骨架 · 批准后解锁草稿
```

点「采纳」才算批准（写入 `chapters/ch-012/meta.json` 的 `skeletonApproved: true`）。
**不采纳 = 没批准**，下一步会被硬拦。

## 2. 出草稿

骨架批准后，稿纸工具条点「写草稿」。

- AI 走 `propose_draft`，产出仍是提案，进收件箱。
- 没批准骨架时，工具会直接拒绝：「第 N 章骨架未获作者批准，不能出草稿」。
- 采纳草稿时：先把当前正文快照到 `chapters/ch-NNN/snapshots/`，再整章写入。拒绝采纳则正文一字不动。

## 3. 改正文

- 直接在稿纸里改；停止输入约 1.5 秒自动保存，也可以 ⌘S。
- 保存会记一条改动（作者来源），可在「资料 → 改动记录」里撤销。
- 空正文保存不会把章节标成成稿。

## 4. 撤销与冲突

侧栏「资料 → 改动记录」：

- **单条撤销**：把文件写回那次改动之前。
- **整批撤销**：同一批次（一次保存/一次采纳）一起退回。
- **冲突**：如果文件在那之后又被改过，撤销会被拒绝并提示冲突，不会覆盖新内容。

删除 `imports/` 里的知识库文档也会记一条改动，可以撤销恢复。

## 5. 写作档位（会影响 AI 能不能直写）

| 档位 | AI 能做什么 | 正文 |
|---|---|---|
| 辅助（默认） | 只能 `propose_*` 提案 | 不能写 |
| 共写 | 可直接写台账（`write_ledger`） | 仍不能写，只能出建议 |
| 代笔 | 可写台账 + 授权章节的正文（`write_prose`） | 仅作者逐章勾选的章 |

档位以书目录的 `zhibi-auth.json` 为准。第一次打开一本书时，如果还没有这个文件，会把设置页的「默认写作档位」落进去；之后以书内文件为准。详见 [权限与安全边界](GUIDE-PERMISSIONS.md)。

## 6. 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| 「写草稿」后 AI 说骨架未批准 | 骨架提案还在收件箱没采纳 | 去收件箱点采纳 |
| 采纳草稿失败，提示「采纳被拒」 | 落库后台账结构不合法，已整档回滚 | 修提案或重出；正文未变 |
| 改动记录里撤销被拒 | 文件在那之后又被改过 | 先确认当前版本，再决定是否强改 |
| 章节页显示「未动笔」 | 正文为空或只有空白 | 写入正文并保存 |
